Overview

Fifteen real games.
Screenshots in, keystrokes out.

  1. Commercial games, untouched. Every game is someone else's product. No hooks, no APIs, no simplified ports.
  2. Progress from the game itself. Milestones are checked against native game evidence, not against the agent's own report.
  3. Two clocks. Each real-time game runs live, where the world keeps moving while the agent thinks, and frozen, where it waits.

Live versus frozen

The world does not wait.
Same agent, same game, two clocks.

In live execution the game keeps running while the agent reasons, so its input lands on a later moment than the one it saw. In frozen execution the harness suspends the game during inference. Below, one agent drives two roads with its real median latency, sped up four times.
