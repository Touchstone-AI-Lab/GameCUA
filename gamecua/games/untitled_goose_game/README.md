# Untitled Goose Game

This integration runs the official Windows Steam build (App ID 837470) through Proton Experimental. Preparation requires one successful official-client launch and a private snapshot containing the Proton prefix metadata. Every episode restores that metadata into an isolated profile, removes all slot saves and starts at the title screen.

The game is real-time because its world continues while the model reasons. Live Trials preserve that behavior; frozen Trials suspend the owned game process during decisions and execute each selected action for one second. Both DeepSeek and Jev use `untitled-goose-game-pointer-v2`. Each step pairs one pointer action (left click on a menu option, button or walk destination; right click with the beak; hover to aim; or none) with one held key (bend, honk, flap, task list or none), without route or puzzle hints.

The game declares a time budget because there is no native run-ending death: DeepSeek receives 3 hours and Jev 1 hour, each in live and frozen modes. The `untitled-goose-game-victory-v4` rubric awards ten 10-point milestones: the first garden task, the completed garden list, three main-list tasks and the completed list in each of the high street, back gardens and pub, taking the model-village bell, and the native bell-return finale. These measure the main task-list progression and ending; optional post-game lists and unrelated interactions earn no points. No cross-area prerequisite is imposed, so native progress remains creditable if an area is left with unfinished tasks. The published v3 rubric remains unchanged for historical results. Earlier completed runs can be rescored when their preserved native saves contain these task flags. Progress comes only from game-written BinaryFormatter slot saves. The fixed village has no gameplay seed. Licensed files, Steam state and the Proton prefix stay outside the repository. Every episode starts at the title screen with no slot saves, so `snapshots/untitled-goose-game/` holds only `new.txt`.
